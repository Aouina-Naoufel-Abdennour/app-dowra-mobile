# Charte Dowra

Maquettes de référence : canvas Claude Design « Maquettes app Dowra » (charte mauve, logo, mascotte, site, app 15 écrans).

- **Couleurs** : `tokens.json`. Le dégradé mauve sert à une seule action forte par écran ; le jaune `#FFD21F` est un petit signal (prix, promo, dernières places) ; neutres teintés mauve.
- **Polices** : Plus Jakarta Sans (texte, titres en italique dégradé), Caveat (petites étiquettes manuscrites), Noto Kufi Arabic.
- **Logo « la boucle »** (`logo/`) : un « d » dont la panse est un trajet aller-retour, le point jaune est la destination.
- **Mascotte Dowri** (`dowri/`) : le « d » du logo qui prend vie, le point jaune devient son nez. 8 humeurs : salut, content, fête (réservé), billet, route, carte (recherche), repos (écran vide), triste (erreur). Présent partout dans le site et les apps.
